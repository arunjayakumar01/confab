# Confab keyboard shortcuts for Google Chat

Press `⌘/` in the app to see this list. `Ctrl` works in place of `⌘` for most shortcuts when you run Confab outside macOS, although the on-screen hints still show `⌘`.

## Navigate

| Shortcut | Action |
| --- | --- |
| `⌘K` | Jump to a space or person |
| `⌘[` and `⌘]` | Back and forward through spaces |
| `⌥↑` and `⌥↓` | Previous and next space |
| `⌥⇧↑` and `⌥⇧↓` | Previous and next unread |
| `⌘⇧A` | Unreads |
| `⌘⇧S` | Saved |
| `⌘⇧T` | Todos |
| `⌘F` | Search messages |

## Write

| Shortcut | Action |
| --- | --- |
| `↵` | Send |
| `⇧↵` | New line |
| `↑` | Edit your last message |
| `⌘B` and `⌘I` | Bold and italic |
| `⌘⇧X` and `⌘⇧C` | Strikethrough and code |
| `@` and `:` | Mention someone and emoji |

## Window

| Shortcut | Action |
| --- | --- |
| `⌘N` | New message |
| `⌘.` | Thread panel |
| `⌘=`, `⌘-` and `⌘0` | Zoom in, zoom out and reset |
| `⌘/` | Shortcut list |
| `Esc` | Close whatever is open |
