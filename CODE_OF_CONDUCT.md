# Code of conduct

This project welcomes everyone, and we expect people to be respectful in issues, pull requests and every other project space.

Harassment, personal attacks, discrimination, and publishing someone's private information are not acceptable.

The maintainer may edit or remove contributions, or block participants, when this code isn't followed. To report a problem privately, use [private vulnerability reporting](https://github.com/arunjayakumar01/confab/security/advisories/new) and say that it is a conduct report.
