A desktop client for Google Chat

Confab is an unofficial, open source app for Google Workspace. Sign in with your account and get your spaces, threads, huddles, calendar, tasks and notes in one window, in sync with Chat everywhere else.

Get the code on GitHub Try it without an account

Early software. Tested on macOS, built from source, and free under the MIT license.

Everything in Google Chat, and the rest of your workday beside it

Spaces, messages and threads

Spaces, direct messages and group chats share one sidebar. Threads open in a side panel, and messages from the same person group into one clean block. Press ⌘K to jump anywhere.

Huddles and Google Meet

Start a huddle in a named space, or get a Join and Decline popup when someone else starts one. Calls run in the real Google Meet, in a small window that stays on top.

Google Calendar next to your chats

Month, week, day and agenda views. Create events, answer invites, and join a call from the countdown in the top bar.

Google Tasks and notes

Turn any message into a task in your default Google Tasks list. Notes are saved privately in your own Google Drive, so they appear wherever you sign in.

File previews
PDFs, Word documents, spreadsheets, zip archives, code, video and audio open inside the app.
Several accounts
Keep Google accounts side by side, each with its own unread badge.
Shared status
Set your status and do not disturb here, and Gmail and Chat show the same thing.
Catching up
Read unreads by space, bookmark messages and jump straight back to them.
Local search
Search messages from a cache on your own machine.
Careful link previews
Confab asks first by default, because fetching a page shows that site your address.

Two ways to start

Look around first

No Google account needed. This runs the interface in your browser with a made-up team. You only need Node and pnpm for this.

  1. Get the code
    git clone https://github.com/arunjayakumar01/confab.git
  2. Install
    cd confab && pnpm -C apps/desktop install
  3. Run, then open localhost:1430
    pnpm -C apps/desktop dev:mock

Connect your Workspace

About ten minutes, and the setup script does most of it. You need:

  • A Google Workspace Business or Enterprise organisation
  • A Google Cloud project inside it, which you control
  • Admin rights for its consent screen and Chat API settings
make gcp-setup PROJECT=my-project ACCOUNT=you@your-org

Questions, answered in chat

Is there a desktop app for Google Chat?

Confab

Confab is an unofficial desktop client for Google Chat. It runs as a desktop app on macOS today and talks to Google's APIs directly, rather than wrapping the Chat website.

Does it work on Windows, Linux or the web?

Confab

Not yet. macOS is the only platform tested so far, and web, Linux and Windows are on the roadmap.

Does it work with a personal Gmail account?

Confab

No. Setup needs a Google Workspace Business or Enterprise organisation and a Google Cloud project inside it.

Is it free and open source?

Confab

Yes. Confab is free under the MIT license. You run the relay yourself, and any Google Cloud costs for your project are yours.

Can I join Google Meet calls and huddles?

Confab

Yes. Calls run in the real Google Meet, in a small window that stays on top. Confab can start a huddle in a named space and show a Join and Decline popup when someone else starts one.

Does everyone on my team need Confab?

Confab

No. Messages reach teammates in Google Chat as usual. Typing indicators, other people's online status and read receipts only come from teammates who also use Confab.

Who can see my messages and tokens?

Confab

Your tokens are stored on your machine, and there is no Confab-hosted server. Your access token and new message events pass through the relay you run, so treat that relay as part of your own infrastructure.

Is Confab made by Google?

Confab

No. Confab is an independent project and is not affiliated with Google.
